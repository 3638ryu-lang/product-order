# product-order

대명한의원 제품 주문 페이지입니다. 결제 없이 주문 정보만 접수하며,
접수된 주문은 구글 스프레드시트에 자동으로 기록되고 관리자 이메일로 알림이 발송됩니다.

한의원 공식 홈페이지(`daemyung` 저장소)와는 완전히 분리된 독립 사이트입니다.

## 시작하기

1. `index.html`을 열어 `PRODUCTS` 목록을 실제 판매 제품으로 수정하세요.
2. `ORDER_SYSTEM_SETUP.md` 안내에 따라 구글 스프레드시트 연동과 이메일 알림을 설정하세요.
3. GitHub Pages, Netlify 등으로 배포하면 독립적인 주소로 바로 서비스할 수 있습니다.
